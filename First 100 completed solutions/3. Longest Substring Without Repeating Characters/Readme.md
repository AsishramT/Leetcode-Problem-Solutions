# 3. Longest Substring Without Repeating Characters

Given a string `s`, find the length of the longest substring without duplicate characters.

---

## Example 1:

```
Input: s = "abcabcbb"
Output: 3
``` id="a1b2c3"

Explanation:
The answer is `"abc"`, with length 3.  
(Also valid: `"bca"`, `"cab"`)

---

## Example 2:

```
Input: s = "bbbbb"
Output: 1
``` id="d4e5f6"

Explanation:
The answer is `"b"`.

---

## Example 3:

```
Input: s = "pwwkew"
Output: 3
``` id="g7h8i9"

Explanation:
The answer is `"wke"`, with length 3.  
Note: `"pwke"` is not valid because it is not a substring.

---

## Constraints:

- `0 <= s.length <= 5 * 10^4`
- `s` consists of English letters, digits, symbols, and spaces.
