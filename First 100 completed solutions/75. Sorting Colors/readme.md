# 75. Sort Colors

[75. Sort Colors](https://leetcode.com/problems/sort-colors/)

Given an array `nums` with `n` objects colored red, white, or blue, sort them **in-place** so that objects of the same color are adjacent in the order:

- red = 0
- white = 1
- blue = 2

You must solve this problem without using the library's sort function.

---

## Example 1

```
Input: nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]
``` id="a1b2c3"

---

## Example 2

```
Input: nums = [2,0,1]
Output: [0,1,2]
``` id="d4e5f6"

---

## Constraints

- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` is either `0`, `1`, or `2`
```
